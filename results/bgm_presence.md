# How much real background music is in the dataset? (PANNs audit, D114)

Generated by `python -m bgm.analysis.bgm_presence` (src/bgm/analysis/bgm_presence.py). PANNs CNN14 (AudioSet, 527 classes, frozen, fp32, 4 s context per second) on every second of the 1,248 music files (23,992 s = 6.66 h). Two runs: **raw audio** (the music as delivered) and **hum removed** (high-passed at 150 Hz, file set to −20 dBFS; panns_tags.extract_hp), because Konjum salangai's raw audio carries a +0.06 DC offset and a 100 Hz hum over very quiet music (its sound is ~27 dB quieter than the other sources), which the raw run hears as silence. Per second, in this order: **silent** (raw: RMS < −50 dBFS; hum removed: RMS above 150 Hz < −60 dBFS, i.e. hum or silence only), **speech** (P(Speech) ≥ 0.5, P(Music) < 0.5), **music+speech** (both ≥ 0.5), **music** (P(Music) ≥ 0.5), **weak music** (0.2 ≤ P(Music) < 0.5), **other sound** (the rest). BGM seconds = music + music+speech. File verdict: **clean BGM** (BGM share ≥ 90% and no speech second), **mostly BGM** (≥ 50%), **little BGM** (< 50%). Sections 2–7: the verdicts use the hum-removed run. Per-file table: results/bgm_presence_files.csv.
