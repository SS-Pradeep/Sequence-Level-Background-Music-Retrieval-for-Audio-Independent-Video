# docs/

Written documentation: the build spec, the method write-ups and the decision log.

| File | What it is |
|---|---|
| `PROJECT_BRIEFING.md` | Short overview of the method and the main results. Start here. |
| `METHODOLOGY.md` | Full methodology: data, encoders, heads, retrieval, stitching, change predictor, rendering, evaluation. |
| `METHODOLOGY_FOR_SLIDES.md` | Condensed methodology and results, written for presentation slides. |
| `Video-to-BGM Retrieval Methodology.docx` | Word version of the methodology. |
| `SPEC.md` | The original build specification: milestones M0–M12, data layout, feature keys, metrics. Code comments cite its sections (e.g. "SPEC §5.10"). |
| `PROGRESS.md` | Decision log. Every design choice and experiment is an entry `D1`–`D154`; code and result files cite these IDs. |
| `NEXT_STEPS.md` | Plan written when moving to the film-level split (M8 unblock, learning curve). |
| `PAPER_CORRECTIONS.md` | Differences between the submitted paper and the code/results in this repo. |
| `cue_switch_plan.md` | Plan and Step 0 findings for the learned music-change (cue-switch) predictor. |
| `person_branch_plan.md` | Plan for the person/face-focused scoring branch (experimental, not in the final system). |
| [`inventory/`](inventory/) | List of files kept and deleted in the 2026-11-26 disk cleanup. |
