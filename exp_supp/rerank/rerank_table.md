# Re-rankers on the top-20 shortlist (supplementary, D148)

Cleaned dataset (cleaned_dataset/, D115), title split (cleaned_dataset/manifests/folds_title.json), 5 folds. Retrieval heads fixed: the D116 siglip-both InfoNCE heads (runs/cleaned/semantic/siglip-both). Hit rule = track_id (the M5 / D145 protocols). Only the base top-20 shortlist of each query is re-ordered; everything below it keeps its base order, so a hit outside the top 20 keeps its rank. Ties after re-ranking are broken by the base score. Every parameter is chosen per run on the fold's val films (criterion R@10 + 0.1·MRR), then test is scored once. 'Other queries' for k-reciprocal, mutual kNN and dual softmax = the fold's training clips (track) / 1,500 training segments (segment), never val or test queries.

Single head = one seed, mean ± std over 50 runs (5 folds × 10 seeds); Ensemble = mean cosine of seeds 0–9 (the D116 ens10 rule), mean ± std over 5 folds. Δ = method − no re-ranking, paired per test query (single: per-query hit@10 / reciprocal rank averaged over seeds), 95% film-group cluster bootstrap, 10,000 resamples; * = CI excludes 0. ms/query = re-ranking time only (numpy, CPU, base retrieval excluded).
